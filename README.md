## System Requirements

- **OS:** Windows 10 or Windows 11 (64-bit)
- **Storage:** ~350 MB installed
- **Display:** 1280×720 minimum
- **Keyboard:** Any standard keyboard

The installer is self-contained. WebView2 runtime is bundled — works offline.

## Installation

1. Download `TYPE HYPE_X.X.X_x64-setup.exe` from the latest release.
2. Double-click the installer.
3. Windows SmartScreen may warn about an unsigned installer — click **More info → Run anyway**. (Code signing certificate is pending before Steam launch.)
4. Follow the installer prompts.
5. Launch **TYPE HYPE** from the Start menu or desktop shortcut.

## About the Game

TYPE HYPE is a Guitar Hero-meets-typing-tutor hybrid. Letters scroll down a neon highway and you press the matching key when they hit the judgment line. Features include:

- **54 training levels** across 9 tiers (Home Row → Full Keyboard)
- **15 exhibition levels** with unique themes
- **3 free-roam modes** (Endless Rain, Karaoke Flow, Accuracy Challenge)
- **5 difficulty tiers** (Novice → Expert)
- **Colorblind mode, remappable controls, full audio mixing**
- **27 achievements** and per-level star ratings
